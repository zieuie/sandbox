Canary on fearless first: a connection from uther with IP options set timed out and the counter went to 4 drops, a plain connection worked, gateway ping and SSH fine. Then the other 11; `status` on all 12 shows the rule loaded, include present, nftables enabled. `add_wired_worker.sh` now installs it on new machines. No reboots, no processes touched.
